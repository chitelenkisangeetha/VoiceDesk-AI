# VoiceDesk AI 🎙️

VoiceDesk AI is a voice-based personal AI assistant built using Python, Streamlit, Speech Recognition, Text-to-Speech, and Ollama.

## Features

- 🎤 Voice input
- 💬 Text-based chat
- 🤖 AI responses using Llama 3.2
- 🔊 Text-to-Speech
- 🌐 English and Telugu voice support
- 🕐 Current time and date commands
- 💬 Chat history
- 🎨 Simple and user-friendly interface

## Technologies Used

- Python
- Streamlit
- Ollama
- Llama 3.2
- SpeechRecognition
- PyAudio
- pyttsx3
